---

## Что это?

**Братва** — полноценное приложение для прослушивания музыки на SoundCloud.
Написано на Tauri 2 + React 19 — работает нативно, потребляет минимум ресурсов и не тормозит.

Работает на Windows, Linux и macOS.

---

## Почему Братва

### Доступно в России

SoundCloud заблокирован Роскомнадзором — веб-версия не открывается. Братва работает напрямую без каких-либо дополнительных программ. Весь каталог SoundCloud доступен полностью.

### Никакой рекламы

Ноль рекламных баннеров, ноль промо-вставок между треками, ноль всплывающих окон «оформи подписку». Чистый интерфейс, только музыка.

### Без капчи

Никаких бесконечных проверок «я не робот». Открыл — слушаешь.

### Без цензуры

Доступ ко всему каталогу SoundCloud без региональных ограничений. Все треки, все артисты, все жанры.
---

## Возможности

- Полный каталог SoundCloud: поиск, лайки, плейлисты, альбомы, артисты
- Собственный аудио-движок на Rust (rodio + symphonia): mp3 / aac / ogg / flac
- Эквалайзер на 10 полос, пресеты, импорт APO / Peace / GraphicEQ
- Регулировка питча и темпа без потери качества
- Анализатор спектра в реальном времени
- Системные media-контролы (SMTC / MPRIS) и Discord Rich Presence
- Кеш треков для офлайн-прослушивания, отдельная квота под лайки
- Перенос хранилища на другой диск
- Синхронизация лайков и плейлистов с аккаунтом SoundCloud
- QR-логин и кросс-устройственная авторизация
- Скробблинг в ListenBrainz
- Импорт лайков из Яндекс.Музыки
- Горячие клавиши, автозапуск, компактный режим в трее

## Сборка из исходников

Требования: Node.js 20+, pnpm 10+, Rust 1.99.1 (toolchain в `rust-toolchain.toml`),
Visual Studio Build Tools с MSVC, WebView2 Runtime (на Windows 10/11 обычно уже есть).

```bash
cd desktop
pnpm install
pnpm tauri dev     # запуск в dev-режиме
pnpm tauri build   # релизная сборка: NSIS .exe + MSI
```

Криптография обновлений в исходниках не настроена (инжектится в CI оригинала) —
сборка работает, автообновление выключено.
